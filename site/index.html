Props & accessibility

All spinners accept size (pixels), color (CSS color), speed (seconds per cycle), label, paused, and decorative. Add className or style as needed.

Default label: “Loading”. Use decorative when nearby text already describes the loading state. Reduced-motion preferences are respected automatically.
